# Mindtone Mental Health Clinic — Outpatient Wait-Time AI

Task 5 Final Project: an AI system to predict and reduce outpatient wait
times at Mindtone Mental Health Clinic (Psychiatry, Counseling, Addiction
Therapy).

## Problem

Patients wait an average of 26 minutes to be seen, rising to 49 minutes for
the slowest 10% of visits — driven by static scheduling, unmanaged walk-ins,
and peak-hour bottlenecks. See `docs/Business_Problem_Analysis.docx` for the
full analysis.

## Solution

A Gradient Boosting regression model predicts each patient's expected wait
time in real time from operational features (queue depth, staffing,
department, time of day, appointment type). Predictions feed a queue
optimizer that routes walk-ins to the least-loaded clinician and smooths
peak-hour load. Full design in `docs/AI_Solution_Proposal.docx`.

## Results

| Model | MAE (min) | RMSE (min) | R² | Train time (s) |
|---|---|---|---|---|
| **XGBoost (selected)** | 5.25 | 6.61 | 0.845 | 0.21 |
| Gradient Boosting | 5.37 | 6.74 | 0.839 | 1.07 |
| Random Forest | 6.51 | 8.14 | 0.765 | 2.20 |

XGBoost was selected: it's marginally more accurate than scikit-learn's
Gradient Boosting and trains 4–8x faster, which matters for the system's
scheduled retraining cycle described in the AI Solution Proposal.

Simulated impact of AI-optimized scheduling vs. the current process:

| Metric | Current | AI-optimized | Change |
|---|---|---|---|
| Average wait time | 26.0 min | 18.5 min | -28.6% |
| 90th-percentile wait | 49.0 min | 34.2 min | -30.2% |

## Repo structure

```
data/     synthetic dataset + generator script
model/    training, simulation, and diagram-generation scripts
results/  trained model, metrics, and charts (generated by scripts in model/)
docs/     business analysis, solution proposal, risk analysis, cost/timeline,
          client presentation, technical presentation notes, code review guidelines
```

## Setup & run

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python3 data/generate_dataset.py       # generates data/mindtone_wait_times.csv
python3 model/train_model.py           # trains model, saves results/*.png + metrics.json
python3 model/simulate_impact.py       # projects AI-optimized wait-time reduction
python3 model/architecture_diagram.py  # generates results/architecture_diagram.png
python3 model/timeline_chart.py        # generates results/timeline_gantt.png
```

Each script is independent and reads/writes relative to the repo root, so
run them from the top-level `mindtone-wait-time-ai/` directory.
